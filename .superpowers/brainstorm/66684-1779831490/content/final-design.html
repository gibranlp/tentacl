Tentacl Design Summary

Confirming the final blueprint for Tentacl.

Project Core

  • Identity: Tentacl - Unlimited, License-free Docker Manager.
  • Focus: Local VPS Management (Unix Socket integration).
  • Aesthetic: Terminal/Dark Mode. Monospace, high-contrast, "Hacker" vibe.

Technical Stack

Backend: Go

Direct Docker SDK usage. REST API. Single static binary output.

Frontend: React

Tailwind CSS (Dark theme). TypeScript. Vite/Esbuild for speed.

DB: BoltDB

Embedded K/V store. No external dependencies.

Feature Roadmap (MVP)

Included

  • Container Lifecycle (Start/Stop/Logs)
  • Image Management (Pull/Remove)
  • Network Management (List/Create/Inspect)
  • Volume Tracking
  • Real-time Stats (CPU/MEM)

Out of Scope (For Now)

  • Remote Hosts (SSH/TLS)
  • User Role Permissions (RBAC)
  • Kubernetes Support
