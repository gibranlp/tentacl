Tentacl Project Overview

A lightweight, license-free Portainer clone for personal VPS management.

Core Objectives

  • Unlimited: No feature gates, no seat limits, no "Business Edition" upsells.
  • Lightweight: Low memory footprint for VPS environments.
  • Docker-First: Focused on managing Docker containers, images, volumes, and networks.
  • Standalone: Easy to deploy as a single binary or container.

Proposed Tech Stack

G

Go Backend

Efficient, fast Docker API integration, compiles to static binary.

R

React Frontend

TypeScript + Tailwind CSS for a modern, responsive dashboard.

B

Embedded DB

BadgerDB or BoltDB. No external database setup required.

Phase 1 Features

Dashboard

Overview of running containers, CPU/RAM usage.

Container Management

List, Start, Stop, Restart, Remove, Logs, Stats.

Image Management

List, Pull, Push, Remove images.
